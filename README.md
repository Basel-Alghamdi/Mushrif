# رَصد — منصة متابعة الفريق التنفيذي

منصة عربية (RTL) لرئيسة النطاق وفريقها:

- **رئيسة النطاق:** أول صفحة لها محادثة مع **مساعد ذكي** (مثل ChatGPT) مع سجل المحادثات السابقة. تسأله عن أي مشرفة أو أي رقم، وترفع ملفات Excel/Word/PDF داخل المحادثة فيعبّئ البيانات في ملفات المشرفات بعد موافقتها بضغطة واحدة.
- **المشرفات:** كل مشرفة تدخل ببريدها وتختار كلمة مرورها أول مرة، ثم أربعة أقسام واضحة: اليوم · مدارسي · تقاريري · بياناتي.
- المنصة نفسها تعمل على الجوال والكمبيوتر بدون نسخة منفصلة.

## التشغيل المحلي

```bash
pnpm install
cp .env.example .env                    # ثم أضف مفاتيح Supabase (انظر docs/INTEGRATIONS.md)
pnpm --filter @rasd/api db:migrate      # يستخدم DIRECT_DATABASE_URL، أو DATABASE_URL إن لم يُضبط
pnpm --filter @rasd/api bootstrap:head  # النطاق وحساب رئيسة النطاق
pnpm --filter @rasd/api seed:roster     # حسابات المشرفات من ملف الفريق (انظر أدناه)
pnpm local                              # يبني الواجهة ويشغّل المنصة: http://localhost:3000
```

أو للتطوير مع إعادة التحميل التلقائي: `pnpm dev`.

- الواجهة: `http://localhost:3000` — ومن الجوال على نفس الشبكة: `http://<عنوان جهازك>:3000`
- الـ API: `http://localhost:4000` (الواجهة تمرّر طلبات `/api/v1` إليه تلقائياً)

## فريق المشرفات (ملف خاص — لا يُرفع على GitHub)

أسماء المشرفات وبريدهن بيانات شخصية، لذلك لا تُحفظ في المستودع. ضعي ملف Excel الخاص بالفريق (تصدير نموذج التسجيل كما هو: «الاسم رباعي» · «الصفة» · «البريد الالكتروني») في `apps/api/data/roster.xlsx` (المجلد مستثنى من git) ثم شغّلي `pnpm --filter @rasd/api seed:roster`. أو ترفع رئيسة النطاق الملف نفسه في المحادثة فيُنشئ المساعد الحسابات بعد موافقتها.

## الدخول

- **رئيسة النطاق:** تدخل ببريدها وكلمة المرور التي ضُبطت عند الإعداد (`RASD_ADMIN_PASSWORD`).
- **المشرفات:** كل مشرفة تكتب بريدها، وفي أول مرة تختار كلمة مرورها (٨ أحرف على الأقل) خلال ١٤ يوماً من إنشاء حسابها. تصل رئيسة النطاق إشعار عند كل تفعيل.
- نسيت مشرفة كلمة المرور؟ رئيسة النطاق تضغط «إعادة تعيين كلمة المرور» من ملفها (تنتهي كل جلساتها القديمة ولديها ٣ أيام لاختيار كلمة جديدة)، أو تستخدم المشرفة رابط الاستعادة من صفحة الدخول.

## المساعد الذكي

يعمل مباشرة بمحرك عربي مدمج (بدون أي مفاتيح). لتفعيل GPT-5 للفهم الحر وقراءة الملفات الممسوحة ضوئياً أضيفي `OPENAI_API_KEY` و`OPENAI_CHAT_MODEL=gpt-5` في `.env` بجذر المستودع. يمكن استخدام Claude عبر `ANTHROPIC_API_KEY` عند عدم ضبط مفتاح OpenAI.

## البنية

- `apps/web`: Next.js — مساحة رئيسة النطاق (`/district`: المحادثة، الفريق والأرقام)، مساحة المشرفة (`/cluster`)، الدخول والدعوات واستعادة كلمة المرور.
- `apps/api`: Hono على Postgres (Supabase) — المصدر الوحيد للكتابة، مع الصلاحيات وسجل التدقيق، والمساعد (`src/agent`).
- `apps/worker`: مهام الخلفية (قيد الإعداد).
- `packages/schemas`: قواعد بنية الملف ونسبة الاكتمال، وأنواع عقود المحادثة والمستندات — مشتركة بين الواجهة والـ API.
- `packages/i18n`: الأرقام العربية والتاريخ الهجري.
- `supabase/migrations`: مخطط قاعدة البيانات وسياسات RLS.
