# رَصد — منصة متابعة الفريق التنفيذي

منصة عربية (RTL) لرئيسة النطاق وفريقها:

- **خلود — رئيسة النطاق:** أول صفحة لها محادثة مع **مساعد ذكي** (مثل ChatGPT) مع سجل المحادثات السابقة. تسأله عن أي مشرفة أو أي رقم، وترفع ملفات Excel/Word/PDF داخل المحادثة فيعبّئ البيانات في ملفات المشرفات بعد موافقتها بضغطة واحدة.
- **المشرفات (١٨ حساباً جاهزاً):** كل مشرفة تدخل ببريدها، تختار كلمة مرورها أول مرة، ثم تتبع خطوات واضحة: بياناتي ← مدارسي ← ملفاتي ← إرسال التحديث.
- المنصة نفسها تعمل على الجوال والكمبيوتر بدون نسخة منفصلة.

## التشغيل المحلي

```bash
pnpm install
pnpm local      # يبني الواجهة ويشغّل المنصة: http://localhost:3000
```

أو للتطوير مع إعادة التحميل التلقائي: `pnpm dev`.

- الواجهة: `http://localhost:3000` — ومن الجوال على نفس شبكة الواي فاي: `http://<عنوان جهازك>:3000`
- الـ API: `http://localhost:4000` (الواجهة تمرّر الطلبات إليه تلقائياً)
- البيانات محفوظة في `apps/api/data/rasd.sqlite` والملفات المرفوعة في `apps/api/data/uploads/`.

## فريق المشرفات (ملف خاص — لا يُرفع على GitHub)

أسماء المشرفات وبريدهن بيانات شخصية، لذلك لا تُحفظ في المستودع. ضعي ملف Excel الخاص بالفريق (تصدير نموذج التسجيل كما هو: «الاسم رباعي» · «الصفة» · «البريد الالكتروني») في:

```
apps/api/data/roster.xlsx
```

يُنشئ الخادم الحسابات منه تلقائياً عند أول تشغيل (المجلد `apps/api/data/` مستثنى من git). أو ارفعي الملف نفسه لخلود في المحادثة وسيُنشئ المساعد الحسابات بعد موافقتها.

## الدخول

| الحساب | البريد | أول دخول |
|---|---|---|
| خلود — رئيسة النطاق | `khulood@rasd.local` | تكتب البريد ثم تختار كلمة مرور |
| المشرفات | بريد Gmail لكل مشرفة (من نموذج التسجيل) | تكتب بريدها ثم تختار كلمة مرور |

لتغيير بريد خلود: `RASD_ADMIN_EMAIL` في `apps/api/.env`. نسيت مشرفة كلمة المرور؟ خلود تضغط «إعادة تعيين كلمة المرور» من ملفها، فتختار المشرفة كلمة جديدة في الدخول التالي.

## المساعد الذكي

يعمل مباشرة بمحرك عربي مدمج (بدون أي مفاتيح). لتفعيل Claude للفهم الحر وقراءة الملفات الممسوحة ضوئياً، أضيفي في `apps/api/.env`:

```
ANTHROPIC_API_KEY=...
```

## البنية

- `apps/web`: Next.js — مساحة رئيسة النطاق (`/district`) ومساحة المشرفة (`/cluster`) وتسجيل الدخول.
- `apps/api`: Hono + SQLite — الحسابات، ملفات المشرفات، المستندات، المحادثات، والمساعد (`src/agent`).
- `packages/schemas`: أنواع العقد المشتركة بين الواجهة والـ API.
- `packages/i18n`: التنسيق العربي والتواريخ الهجرية.
